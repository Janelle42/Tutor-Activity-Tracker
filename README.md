Tutor Activity Tracker- A web application developed to help tutors record and keep track of their tutoring activities.

Why I Built It- As a tutor myself, I found it difficult to keep track of all the different activities I was involved in, including tutoring sessions, modules, time spent and the number of students reached. I created the Tutor Activity Tracker to make this information easier to record, manage and view in one place.

Features
* Add tutoring activities
* View recorded activities
* View activity details
* Edit activities
* Delete activities
* Dashboard with activity statistics
* Monthly tutoring hours chart
* Input validation

Technologies
* C#
* ASP.NET Core MVC
* .NET 8
* Entity Framework Core
* SQL Server
* HTML
* CSS
* Bootstrap
